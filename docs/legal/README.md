# 장부선생 약관·방침 초안 (2026-11-01)

| 파일 | 내용 |
|---|---|
| `terms-of-service.md` | 이용약관 |
| `privacy-policy.md` | 개인정보 처리방침 |
| `refund-policy.md` | 환불·청약철회 안내 |

**초안이다. 법률 자문이 아니고, 관련 법령(전자상거래법, 개인정보 보호법, 약관규제법 등)의 조문은 직접 확인하지 못했다.** 알려진 일반 원칙을 바탕으로 쓰고, 불확실한 부분은 `[확인 필요]`로 표시했다. 판매 전에 변호사나 약관 검토 서비스로 확인한다.

## 화면 연결 (2026-11-01, 배포 전)
- 체험 화면 푸터에 세 문서 링크, 이용권 입력창에 동의 체크(필수)와 "코드를 입력해 이용을 시작하면 청약철회가 제한될 수 있습니다" 문구가 들어갔다.
- `node scripts/build-legal.js`가 이 폴더의 md를 `dist-public/legal/*.html`로 바꾸고, `deploy-server.js`가 서버에 같이 올린다. 페이지 상단에 "초안" 표시와 `[확인 필요]` 강조가 보인다. **확정본으로 바꿀 때 이 표시를 지운다**(`scripts/build-legal.js`의 draft 문단).
- 동의 여부는 서버에 기록하지 않는다(개인정보 최소화). 분쟁 대비 기록이 필요하면 발급 장부나 판매 채널 기록을 쓴다. [확인 필요]

## 판매 전에 채워야 하는 값
- `[상호]` `[대표자]` `[사업자등록번호]` `[통신판매업 신고번호]` `[사업장 주소]` `[연락처 이메일]`: 사업자 등록·통신판매업 신고 뒤에 알 수 있다. 개인 주소·전화는 사업장 주소 등으로 대체할 방법을 확인한다.
- `[시행일]`, `[개인정보 보호책임자]`.
- 판매 채널(스마트스토어 등)의 약관과 겹치는 부분(환불, 개인정보)은 채널 정책이 우선하는지 확인한다.

## 현재 구현과 맞춰 둔 사실 (바뀌면 방침도 고친다)
- 장부 파일·입력값은 서버로 보내지 않는다(브라우저 안에서만 계산).
- 서버에는 이메일·코드·기기 값의 **해시**만 저장한다. 접속 주소(IP)는 해시로 시간당 횟수만 세고 약 1시간 뒤 사라진다(`server/worker.mjs`의 `bumpIp`, 3700초).
- 이용권 토큰과 기기 값은 이용자 브라우저의 로컬 저장소(localStorage)에 둔다.
- 운영자 PC에는 발급 장부(이메일 원문·코드·주문번호 메모)가 있다(`scripts-private/license-ledger.json`).
- 화면은 Cloudflare(호스팅), Google Fonts, cdnjs(SheetJS)를 불러온다. 이용자 접속 정보가 이 서비스로 전달될 수 있다. 외부 CDN 제거(PRD B-4)를 하면 방침에서 줄인다.
- 이용 기간: 2026년 귀속 신고 시즌, 2027-06-30까지. 가격 50,000원. 기기 3대.

## 확인할 것 (미확인)
1. 디지털 콘텐츠의 청약철회 제한 요건과 고지 방식, 시험 사용(체험 버전) 제공이 요건에 도움이 되는지.
2. 개인정보 처리방침 필수 기재 항목 최신 기준, 국외 이전(Cloudflare) 고지·동의 필요 여부.
3. 영수증·계약 기록 보존 기간(전자상거래법 보존 의무 기간).
4. 이메일 해시 저장이 개인정보에 해당하는지(재식별 가능성). 안전하게 개인정보로 보고 처리방침에 썼다.
5. 면책 조항의 유효 범위(약관규제법상 불공정 조항 여부).
6. (환급 점검 기능 추가 시) 개별 신고서의 이월결손금 점검이 세무사법상 세무 상담·대리에 해당하는지, 허용되는 문구 범위. `docs/PRD-refund-check.md` §4.
6-1. 세무 관련 표시·광고에서 "세무 대리"로 오인되지 않는 표현.
7. (확인함) 이메일 해시별 실패 기록(`fl:` 키)은 잠금 시간 15분 + 1시간(약 75분) 뒤 자동 삭제된다(`recordFail`). 방침에 반영함.
