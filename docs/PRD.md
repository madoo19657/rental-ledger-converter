# PRD: 임대사업자 복식부기 변환 도구 (rental-ledger-converter)

- 상태: 초안 v0.1
- 작성일: 2026-10-31
- 작성 배경: 간편장부대상자인 임대사업자가 복식부기로 장부를 작성해 기장세액공제를 받을 수 있게, 간편장부 기록을 법정 표준양식으로 변환하는 도구

> 참고 자료 출처와 열람 상태: [sources.md](sources.md). 간편장부 작성법 정리: [simple-ledger-guide.md](simple-ledger-guide.md). 홈택스 절차: [hometax-manual.md](hometax-manual.md).

> 이 폴더는 `init_project.py`로 만든 프로젝트가 아니라 PRD를 두기 위한 임시 위치다. 개발을 시작할 때 프로젝트 형태(단일 HTML 도구 / 에이전트 프로젝트)를 정하고 옮긴다.

---

## 1. 배경과 문제

- 간편장부대상자(예: 부동산임대업 수입 7,500만 원 미만)는 간편장부만 써도 되지만, **기장세액공제는 복식부기로 기록한 경우에만** 받는다. 신고서의 기장세액공제신청서(별지 제10호의3)에도 같은 조건이 적혀 있다. 간편장부 기록 시 5% 공제는 2010년 귀속분으로 끝났다.
- 복식부기 장부(재무상태표·손익계산서·합계잔액시산표)는 개인이 직접 작성하기 어렵고, 대부분 세무사에게 맡겨 비용이 든다.
- 소규모 임대사업자는 이미 수입·경비를 간편장부 형태로 갖고 있다. 이를 복식 구조로 바꿔 주는 도구가 있으면 세무사 검수 비용과 작업 시간을 줄일 수 있다.

## 2. 목표와 비목표

### 목표
1. 간편장부 데이터와 최소한의 추가 정보로 **복식 분개를 자동 생성**한다.
2. 분개로부터 **합계잔액시산표 → 표준재무상태표 → 표준손익계산서**를 법정 서식 형태로 산출한다.
3. **기장세액공제**(신청서 값), **임대보증금 총수입금액 조정명세서(간주임대료)**, **조정계산서(별지 제46호)** 를 계산한다.
4. 모든 결과는 대차평형과 상호 정합성 검증을 통과해야 출력된다.
5. 세무사가 검수하기 쉽게 계산 근거를 추적할 수 있다.

### 비목표 (v1)
- 홈택스 전자신고 자동 제출·연동 (공개 API 없음)
- 신고서 본문(종합소득세 신고서) 자동 작성, 소득공제·세액공제 전반 계산
- 세무조정 전반의 자동 판단. 조정계산서는 간주임대료 가산과 사용자가 입력한 조정 항목만 반영하고, 필요경비 불산입 여부(사적 대출 이자 등)는 도구가 판단하지 않는다
- 주택임대, 공동사업자, 법인, 부가가치세 신고
- **v1 구현은 사업장 1곳으로 시작한다** → [scope-v1.md](scope-v1.md). 아래 다수 사업장은 입력 구조만 대비하고 합산은 v1.1
- (다수 사업장은 v1 범위로 변경: 실제 간편장부가 사업장별 시트 구조이며 기장세액공제 한도는 사업장 합산 기준. [input-format.md](input-format.md) 1장)
- 세무 상담, 절세 조언
- 사용자 계정·서버 저장

## 3. 사용자

| 구분 | 설명 | 필요 |
|---|---|---|
| 주 사용자 | 간편장부대상자인 개인 임대사업자(상가 1~3개 수준) 또는 그 가족 | 쉬운 입력, 결과 신뢰 |
| 보조 사용자 | 세무사·기장 담당자 | 근거 추적, 서식 출력, 수정 가능 |

## 4. 핵심 시나리오

1. 사용자가 연도, 사업자 기본정보(상호, 사업자등록번호는 선택)를 입력한다.
2. 간편장부 파일(엑셀/CSV)을 올리거나 화면에서 직접 입력한다.
3. 기초 잔액과 건물 정보, 임대보증금 정보를 입력한다.
4. 도구가 분개를 만들고 검증 결과(대차평형, 잔액 일치)를 보여 준다.
5. 사용자(또는 세무사)가 분개를 확인·수정한다.
6. 표준서식 PDF와 기장세액공제 계산서, 간주임대료 명세서를 내려받는다.

기본은 현금주의 간편장부를 복식 구조로 옮기되, 아래를 추가한다.

- 선수·미수 임대료 등 발생주의 조정은 P1.
- 재무상태표의 자본은 `기초자본 + 당기순이익 + 투입 − 인출`이다.

## 7. 세법 규칙·파라미터 (연도별 설정으로 분리)

세법 값은 코드에 박지 않고 `tax-params/{연도}.json`로 둔다.

1. **기장세액공제**
   - 공제세액 = 산출세액 × (기장소득금액 ÷ 종합소득금액) × 20%
   - 한도 100만 원 (사업장별 합계 기준)
   - 대상: 간편장부대상자가 복식부기로 기장한 경우
   - 입력: 종합소득 산출세액은 사용자가 신고서에서 가져와 입력(도구는 전체 종합소득세를 계산하지 않음)
2. **간주임대료 (주택 제외 부동산)**
   - 보증금 적수와 건설비 상당액 적수의 차 ÷ 365(윤년 366) × 이자율 − 보증금 운용수입
   - 건설비 상당액 = 건물분 취득가액 × (보증금 받고 임대한 면적 ÷ 연면적)
   - 이자율은 연도별 파라미터 (2025년: 3.10%)
3. **간편장부대상 기준**: 업종별 수입금액 기준(부동산임대업 7,500만 원 등)을 파라미터로 두고 경고 표시

위 규칙의 법령 조문 확인은 개발 착수 전에 세무사와 한다(열린 질문 참고).

## 8. 법적·윤리적 제약

- 세무사가 아닌 사람이 대가를 받고 신고서를 대신 작성하는 것은 세무사법 위반이 될 수 있다. v1은 **본인 입력·계산 보조 도구**로 한정하고, 유료 대행처럼 보이는 문구와 구조를 피한다.
- 출력물에 "세무사 검수 권장, 신고 책임은 신고인에게 있음"을 명시한다.
- 기장세액공제는 실제 복식부기 기록과 증빙이 있어야 한다. 도구는 거래 단위 분개와 증빙 체크리스트를 제공하며, 사후 가공을 조장하는 문구를 쓰지 않는다.

## 9. 비기능 요구사항

- **개인정보**: 주민등록번호는 수집하지 않는다. 사업자등록번호는 선택 입력. 모든 처리는 브라우저 안에서 하며 서버로 전송·저장하지 않는다.
- **정확성**: 모든 금액은 정수(원) 계산, 소수점 처리 규칙(원 미만 절사)을 명시
- **접근성·사용성**: 모바일에서도 입력 가능, 고령 사용자를 고려한 큰 글씨·단계별 화면
- **출력 품질**: A4 세로, 법정 서식과 같은 항목·코드 번호
- **테스트**: 계산 로직은 단위 테스트로 보호 (10장)

## 10. 수용 기준 (참고 사례 A)

첨부된 실제 신고서 한 건(상가 1개, 수입 29,600,000원)을 회귀 테스트 사례로 쓴다. 개인 식별정보는 제외하고 숫자만 쓴다.

| 항목 | 기대값 |
|---|---|
| 총수입금액(임대수입) | 29,600,000 |
| 판매비와관리비 합계 | 12,684,177 (보험료 814,760, 세금과공과 392,940, 감가상각비 11,476,477) |
| 소득금액 | 16,915,823 |
| 건물 취득가 / 감가상각누계액 / 장부가 | 337,543,460 / 103,288,293 / 234,255,167 |
| 자산총계 | 234,926,525 (현금 671,358 + 건물 234,255,167) |
| 보증금 적수 | 18,200,000,000 (50,000,000원, 365일) |
| 건설비 상당액 적수 | 123,203,362,900 |
| 간주임대료 산입금액 | 0 |
| 산출세액 684,949일 때 기장세액공제 | 136,989 |
| 조정계산서 ⑩결산서상 당기순이익 / ⑪ / ⑫ / ⑬ / ⑯ | 16,915,823 / 0 / 0 / 16,915,823 / 16,915,823 |

사례 C(국세청 작성사례, 2024년 기준, [simple-ledger-guide.md](simple-ledger-guide.md) 5장)도 회귀 테스트로 쓴다: 매출 69,600,000, 필요경비 20,790,000, 건물분 취득가 50,000,000·보증금 150,000,000일 때 간주임대료 1,250,000, 소득금액 50,060,000.

위 값이 모두 일치하고, 시산표 차변합계=대변합계, 자산 = 부채 + 자본이 성립하면 통과한다.

## 11. 성공 지표

- 입력 시작부터 PDF 출력까지 30분 이내(샘플 기준)
- 세무사 검수에서 구조적 오류(대차 불일치, 계정 오분류) 0건

## 13. 열린 질문

1. ~~형태~~ → **확정(2026-10-31): 단일 HTML 도구, 서버 없음**
2. 간편장부 입력 형식: 초안 있음 → [input-format.md](input-format.md), 샘플 [sample-ledger.csv](../samples/sample-ledger.csv). 실제 사용자 파일로 확인 필요
3. "건설비총액"이 건물분 취득가액인지 전체 취득가인지 (참고 사례 A 서류 확인)
4. 감가상각 표시 방식(건물 직접 차감 vs 누계액 별도)과 내용연수 기준
5. 이용 대상: 본인·가족용인가, 일반 공개인가 (세무사법 검토 범위가 달라짐)
6. 간주임대료 관련 시행령 조문과 기장세액공제 요건에 대한 세무사 확인 시점
7. 기장세액공제 외에 표준세액공제(7만 원) 등 신고서 일부를 포함할지
8. ~~토지(비상각 자산)를 장부에 넣을지~~ → **추가 완료(2026-10-31)**: 토지 계정(코드 39)과 입력란, 홈택스 입력값 반영. 사업장1 토지분은 메모 판독이 불확실해 취득 서류로 확인 필요(실제 값은 개인 문서에 있음) ([self-double-entry-guide.md](self-double-entry-guide.md) G-1)
9. 부가세 정산(납부·상계)과 보증금 이자수익 처리 방식 (같은 문서 G-2~G-4). **G-2 부가세 정산은 구현됨(2026-10-31)**: `track` 모드에서 납부(+)·환급(−) 내역과 기초 미납 부가세를 입력받아 결산일에 예수금·대급금을 상계하고 남은 예수금을 부채로 둔다. 기본 모드는 여전히 "제외(공급가액 기준)". **G-4 보증금 이자수익도 구현됨(2026-10-31)**: 영업외수익(코드 64)으로 장부에 넣고 조정계산서 12번에 자동 불산입. **G-3 부가세법상 간주임대료의 부가세도 구현됨(2026-10-31)**: 추적 모드에서 세금과공과 / 부가세예수금으로 분개. 이로써 G-1~G-4가 모두 끝났고 **사례 D(블로그)를 테스트로 전체 재현**한다(재무상태표 1,236,630,000원, 조정계산서 ⑯ 39,600,000원, 기장세액공제 927,000원)
10. 기장의무 점검기: 공동사업장은 1거주자로 보고 구성원이 같은 공동사업장 수입을 합산하는 규칙(S11)을 도구에 넣어, 복식부기의무자가 되어 기장세액공제를 못 받게 되는 시점을 경고할지. 사업장3처럼 수입이 늘어나는 경우 7,500만 원 합계 확인
11. **간주임대료 기준 불일치**: S12 블로그는 조정계산서 11번에 부가세 신고서의 간주임대료(6,000,000원)를 그대로 넣었지만, 국세청 작성사례(S4)는 소득세 간주임대료를 별지 제53호로 계산하며 건설비 상당액과 보증금 운용수입을 차감한다(S12 사례 숫자로 대면 약 3,000,000원). 도구는 S4 방식을 따른다. 세무사에게 확인할 가장 큰 쟁점. ([hometax-double-entry-flow.md](hometax-double-entry-flow.md) 5장)
12. 자기조정 신고에서 세무조정이 있으면 별지 제47호·제53호를 PDF 부속서류로 직접 첨부한다(S12). 이 서식의 출력을 v1에 넣을지(F-31, F-32).
