# 홈택스 메뉴 위치 기록 (이 프로젝트에서 실제 화면으로 확인한 것)

2026-11-01 사용자가 보내 준 홈택스 화면 캡처 기준이다. 홈택스 개편으로 이름이 바뀔 수 있다.

## 세금신고 > 종합소득세 신고

- **종합소득세신고(모두채움·일반·근로·분리과세·종교인포함 및 중간예납·토지등매매차익)**: 정기신고·수정신고·경정청구 작성 화면. 화면의 **"일반 신고" 카드를 펼치면 정기신고 · 수정신고 · 기한 후 신고 · 경정청구 · 파일 변환신고(회계프로그램) 버튼**이 있고, **"경정청구" 버튼**으로 시작한다(2026-11-07 화면 확인. 2025 귀속 경정청구도 이 경로로 제출). 같은 화면의 다른 카드: 모두채움 신고/단순경비율 신고, 근로소득 신고, 분리과세 신고(주택임대/기타/연금소득), 종교인 기타소득 신고, 기한후 환급신고. 위쪽 바로가기: 신고서 미리보기, 신고도움 서비스, 신고내역 조회(접수증·납부서), 신고 부속·증빙서류 제출, 삭제내역 조회.
- 종합소득세 기한후 환급신고 / 신고도움 자료 조회 / 신고도움 서비스 / **중간예납 고지 세액 조회** / (모의계산) 근로·종교인소득 세액비교, 주택 간주임대료 계산, 주택임대 종합·분리과세비교.
- 작성 화면 왼쪽: 신고서 미리보기, 신고도움 서비스, 신고내역 조회(접수증·납부서), **신고 부속·증빙서류 제출**, 삭제내역 조회.

## 세금신고 > 신고서 조회/삭제/부속서류 (경정청구 제출 후 사용)

| 메뉴 | 용도 |
|---|---|
| 전자신고 결과 조회 | 홈택스로 접수한 신고서·경정청구서 조회. 조회 조건: 세목(종합소득세), **신고일자(최대 2년, 1년·2년 버튼)**, 사업자(주민)등록번호, 정보 공개여부, **접수구분(전자신고/서면신고)**. 결과 열에 접수번호(신고서보기)·접수증·납부서·부속서류 제출여부가 있다(2026-11-07 화면 확인) |
| **신고부속서류 제출** | 증빙 PDF 제출 (2018·2019·2021·2022 신고서 등) |
| **전자신고 접수증·납부서 출력** | 접수증 저장(`12_2025경정청구_접수증`), 신고 목록 14건 조회 |
| 전자신고 삭제 요청 | 접수된 전자신고 삭제 요청 |
| 신고내용확인 진행상황 조회 | 신고 내용 확인(심사) 진행 상태 |

## 나의 홈택스

- 세금신고내역: 탭 3개(정기·수정·기한후 신고 / 경정청구 / 신고·소득 통합조회). 조회 기간 최대 1년, 엑셀 내려받기 가능. 전자고지 문서함(미열람 3건)이 왼쪽 위에 있다.

## 납부·고지·환급

- 납부할 세액 조회/납부: 중간예납 고지분, 전자납부번호, 가상계좌.
- 환급 > **환급금 상세조회**: 환급결정일·지급일·계좌, 엑셀 내려받기, 환급계좌개설(변경)신고. 환급 500만원 초과는 계좌개설 신고 안내.
