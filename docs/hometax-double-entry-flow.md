# 홈택스 복식부기(자기조정) 신고 화면 흐름 (블로그 2부 정리)

- 상태: 정리 v0.1 (2026-10-31)
- 출처: **S12** 송채훈 회계사 「부동산 임대사업자 종합소득세 복식부기로 신고하고 100만원 절세하는법 (2부 홈택스 신고)」. 사용자가 캡처 이미지 35장으로 제공. 1부(S11)는 [self-double-entry-guide.md](self-double-entry-guide.md). 출처 대장: [sources.md](sources.md)
- 사례: **2020년 귀속**, 신고 화면의 접수 조회 기간이 2021-04-20~05-20이라 **2021년 5월 신고**로 보인다. 세율, 이자율, 공제 금액이 지금(2025년 귀속)과 다르다.
- 신뢰도: ○ (회계사 개인 블로그, 실제 홈택스 화면 캡처 포함, 법령 인용 없음). 숫자는 6장에서 직접 검증했다.
- 이 글은 **1부에서 복식부기 장부를 다 만들었다는 전제**로, 홈택스에 입력하는 과정만 다룬다. 사업소득만 있고 근로·연금·기타소득은 없는 개인이라고 가정한다.

## 1. 한눈에 보는 순서

글이 든 10단계:

| 번호 | 단계 | 왼쪽 메뉴 번호(캡처) |
|---|---|---|
| 1 | 기본사항 입력(사업장 정보) | 01 |
| 2 | 소득금액명세서 입력 (조정신고 + 사업소득명세서) | 02 |
| 3 | 종합소득금액 및 결손금 | 03 |
| 4 | 소득공제명세서 | 05 |
| 5 | 기부금명세서 | 06 |
| 6 | 세액공제·감면·준비금 | 08 |
| 7 | 가산세명세서 | 09 |
| 8 | 기납부세액명세서 | 10 |
| 9 | 세액계산 | 11 |
| 10 | 신고서 제출 (부속서류 제출) | 12 |

화면 안내: "종합소득세는 왼쪽 메뉴를 순서대로 입력하며 중간 계산을 거쳐 세액계산에서 납부(환급)할 총세액이 산출된다. **일부 값만 고쳤어도 이후 화면은 반드시 [등록하기] 또는 [저장 후 다음이동]을 눌러 거쳐야 한다. 소득종류나 신고유형을 바꾸면 [새로작성하기]를 쓴다.**"

신고 시간: 매일 06:00부터 익일 00:59:59까지, 5월 31일은 23:59:59까지. 마감일에는 24시 전에 접수가 완료되어야 한다.

## 2. 화면별 입력과 사례 값

### 2-1. 시작
- 홈택스 → 종합소득세 신고 → **일반신고서 [정기신고 작성]**. (일반신고서는 사업소득의 기준경비율·간편장부·복식부기, 금융·근로·기타·연금소득용이고, 위쪽의 단순경비율 추계신고서와 다르다.)
- 신고도움 팝업(신고안내·맞춤신고서)은 1부에서 기장의무를 확인했으면 참고만 한다.

### 2-3. 02 소득금액명세서 → 조정신고
**① 조정계산서** (별지 제46호 화면 입력)

| 칸 | 입력 | 사례 값 |

| 12 필요경비산입 및 총수입금액불산입 | 이자수익 | **1,500,000** |
| 13 차가감소득(10+11−12) | 자동 | 39,600,000 |
| 14 기부금한도초과액, 15 기부금이월액 | | 0, 0 |
| 16 당해과세기간 소득 | 자동 | **39,600,000** |

**② 조정후 총수입금액명세서**
- 업종코드 701201 → [코드조회]. 4번 총수입금액 계 = 내수 국내생산품 **60,020,000** (임대수입 54,000,000 + 간주임대료 6,000,000 + 전자세액공제 20,000).
- 8번 부가가치세 과세표준 일반: **60,000,000** (1기·2기 부가세 신고서의 과세표준 합계). 12번 합계 60,000,000.
- 13번 총수입금액 조정 증가 [작성] → 팝업에서 과목 `전자신고세액공제`, 금액 20,000, [등록하기] → [적용하기].

### 2-7. 제출 후 [접수증] → [Step2 신고내역]
- 접수증의 내용이 신고하려던 내용과 같은지 확인한다. **정기신고는 기한 안에 여러 번 신고해도 최종 접수된 신고서만 유효**하다. 세무서 직원 도움을 받아 신고해도 모든 책임은 본인에게 있다.
- 버튼: 인쇄하기, **Step2 신고내역**, 납부하기, 납부서 조회(가상계좌 확인).
- 환급금은 6월 말까지 지급 예정. 국세가 경정되면 지방소득세 환급도 가능(경정청구는 지방자치단체에 직접).
- **개인지방소득세는 지방자치단체에 별도 신고**(2020년 1월 1일부터). 홈택스에서 [지방소득세 신고하기]로 이동한다.
- 신고서 제출 목록의 **부속서류 제출여부가 N**이면 부속서류를 낸다.

### 2-8. 자기조정이면 부속서류를 직접 첨부
글의 설명: 세무대리인이 아닌 **자기조정으로 직접 신고하면서 기업회계기준과 세법의 차이로 세무조정이 생긴 경우, 조정계산서의 관련 서식을 신고서 부속서류로 제출해야 한다.** 회계프로그램은 관련 서식 작성이 편리하지만 자기조정이면 직접 첨부한다. 사례에는 세무조정이 있으므로 다음 두 서식을 작성해 첨부한다.
- **별지 제47호 소득금액조정합계표**
- **별지 제53호 부동산(주택 제외) 임대보증금 등의 총수입금액 조정명세서**

부속서류 제출 방법 (증빙서류제출 → 신고 부속서류 제출)
- 주민등록번호로 조회 → [첨부하기] → [파일선택]. **PDF 파일만 가능**하며 jpg, bmp, gif, tif, png 이미지는 자동으로 PDF로 변환해 제출한다. 첨부 내용은 **육안으로 식별 가능**해야 한다. 한 번에 **50MB 이하**, 초과하면 2개 이상 파일로 나눈다. 같은 파일은 한 번만 첨부된다. 추가 제출은 [부속서류 추가 제출하기].
- 신고서를 수정해 다시 제출했다면 **부속서류도 다시 제출**해야 한다.
- 마지막으로 지방소득세를 납부하면 종합소득세 신고가 끝난다. 결과: 기장세액공제 927,000원으로 약 100만 원 절세.

## 4. 1부 정리의 정정

[self-double-entry-guide.md](self-double-entry-guide.md) 4장에서 "2020년 1기·2기 부가세신고서 **매출세액** 60,000,000원은 오타(실제 6,000,000원)"라고 적었는데 **틀렸다.** 2부 캡처에서 60,000,000원은 **부가가치세 과세표준(일반)** 으로 입력된다(임대수입 54,000,000 + 간주임대료 6,000,000). 1부 본문이 "매출세액"이라고 쓴 것이 **용어 오기**이고, 매출세액은 6,000,000원(= 5,400,000 + 600,000)이 맞다. 해당 문서를 고쳤다.

## 5. 주의할 점과 이견

1. **간주임대료 6,000,000원을 조정계산서 11번에 그대로 넣었다.** 이 금액은 부가세 신고서의 간주임대료(부가세법 기준)다. 국세청 작성사례(S4)는 소득세 간주임대료를 별지 제53호로 계산하고 **건설비 상당액(건물분 취득가)과 보증금 운용수입을 차감**한다. 이 사례의 숫자로 대어 보면 (350,000,000 − 건물 100,000,000) × 이자율 1.8%(2020년, S4의 표) − 이자수익 1,500,000 = **3,000,000원**으로 6,000,000원과 다르다. 글이 53호 명세서를 부속서류로 첨부한다고 하면서 값을 따로 보여 주지 않아 **어느 쪽이 맞는지는 이 글만으로는 알 수 없다.** 제 도구는 S4 방식을 따른다. 세무사 확인이 필요한 가장 큰 쟁점이다.
2. **이자수익을 12번(총수입금액불산입)으로 뺀다**는 점은 제가 1부 정리에서 판단한 내용과 같아 확인되었다.
3. **전자신고세액공제는 두 가지**다. 조정계산서 11번에 가산한 20,000원은 **부가세 전자신고세액공제**(부가세 신고 2번 × 1만 원), 세액공제 화면에 자동 입력된 20,000원은 **종합소득세 전자신고세액공제**다. 이름이 같아 헷갈리기 쉽다.
4. **표준세액공제 70,000원**은 사업소득만 있고 근로소득이 없는 경우다(도움말 참고). 사례 A 신고서(S1)도 70,000원이다.
5. 이 글은 **2020년 귀속**이다. 2025년 귀속과 다른 값들: 세율 구간(2020년 1,200만 원 이하 6%, 4,600만 원 이하 15%, 2025년은 1,400만 원 이하 6%, 5,000만 원 이하 15%), 소득종류 선택 기준 금액, 간주임대료 이자율(2020년 1.8%, 2025년 3.1%), 전자신고세액공제 금액. 도구의 세법 값은 연도별 파일로 분리해야 한다.
6. 대표자 건강보험료를 복리후생비로 넣은 처리(1부)는 여전히 확인이 필요하다.
7. 글은 **세액감면을 받으면 감가상각이 의제된다**고 주의한다. 감가상각 계상이 선택이라는 1부의 설명과 이어지는 내용이다(감면을 받으면 선택이 아니게 될 수 있음).
