# 입력 형식 명세 v0.2 (간편장부 → 변환 도구)

v0.1(국세청 서식 기준 가정)을 **실제 사용 중인 간편장부 엑셀 1건**(3개 사업장, 2025년 귀속)의 구조에 맞춰 고쳤다. 개인정보(이름·주소·임차인·금액 상세)는 이 문서에 쓰지 않는다.

## 1. 실제 파일 구조 (관찰 결과)

한 통합문서 안에 시트가 다음처럼 있다.

| 시트 | 역할 | 도구가 쓰는가 |
|---|---|---|
| 사업장별 거래 시트 ×3 (호실 이름 시트) | 사업장 한 곳의 1년 거래. **입력 원본** | O |
| 간편장부소득금액계산서 | 별지 제82호 서식. 사업장별 수입·경비·소득금액 | 대사(검증)용으로 읽기 |
| 총수입금액및필요경비명세서 | 별지 제82호 부표. 거래 시트를 `SUMIF`로 합산 | 대사용으로 읽기 |
| 교통비사용내역서 | 빈 양식 | 무시 |
| 간편장부작성법 | 작성 메모(장기수선충당금 반환, 취등록세, 부가세 처리 등) | 무시(메모는 6장에 반영) |

핵심 사실
- **사업장 = 시트.** 한 사업자가 사업장 여러 개를 사업장별로 구분 기장한다. PRD의 "다수 사업장" 비목표는 **v1 범위로 바꾼다**(기장세액공제 한도 100만 원도 사업장 합계 기준).
- 거래 시트의 `계정과목` 열이 82호 부표의 `SUMIF` 조건으로 쓰인다. 즉 이 열은 자유 입력이 아니라 **82호 부표 항목명**으로 정해진 어휘이다.
- **감가상각비는 거래 시트에 없다.** 82호 부표에만 사업장별로 따로 들어간다(간편장부대상자는 조정명세서 첨부 불필요라는 메모가 있음). 도구가 건물 정보로 계산한다.
- 거래 시트의 `공급대가`는 수식 `공급가액 + 부가세`, 매출의 `부가세`는 공급가액의 10% 수식이다. 업로드 시 `data_only`로 계산된 값을 읽는다.
- 거래 시트의 행 순서는 날짜순이 아니다(맨 아래에 이전 연도 날짜 행이 있음).

## 2. 거래 시트 열 (입력 원본)

머리글은 1행, 데이터는 2행부터. 머리글 이름으로 열을 찾는다.

| 열 | 머리글 | 형식 | 설명 |
|---|---|---|---|
| A | 날짜 | 날짜 | 거래일 |
| B | 상호 | 문자열 | 거래처(금융기관, 임차인, 관청 등) |
| C | 거래내역 | 문자열 | 예: 임대료, 대출이자, 재산세 |
| D | 구분 | `매출` / `비용` | 수입이면 매출 |
| E | 공급가액 | 정수 | 부가세 제외 금액 |
| F | 부가세 | 정수 | 매출 위주. 이자 등은 비어 있음 |
| G | 공급대가(합계) | 정수 | E+F |
| H | 계정과목 | 82호 항목명 | 3장 어휘 |
| I | 증빙자료 | 문자열 | 4장 어휘 |
| J | 비고 | 문자열 | 대출원금, 이율, 카드명, 세금계산서 발행 메모 등 |

CSV로 받을 때는 맨 앞에 `사업장` 열을 추가한다(XLSX는 시트 이름이 사업장 이름).

## 2-1. 불러올 때 가져오는 것 (2026-10-31 변경)

간편장부에서 **계산에 쓰는 것만** 가져온다.

- **가져오는 열**: 날짜, 구분, 공급가액, 부가세, 공급대가, 계정과목, 증빙자료, 거래내역, 비고. (공급대가는 공급가액+부가세 검증용)
- **가져오지 않는 것**: 거래처(상호) 열. 계산과 출력에 쓰이지 않고 임차인·금융기관 이름이라 개인정보를 줄이기 위해 기본으로 읽지 않는다(`parseLedgerRows(table, { keepParty: true })`로 켤 수 있음). 머리글이 없는 시트(82호 서식, 메모, 빈 양식)는 거래로 읽지 않는다.
- **다른 시트에서 읽는 것**: 82호 서식 시트의 "주업종코드" 값이 하나로 모이면 업종코드를 자동으로 채운다(`detectIndustryCode`). 사용자의 엑셀에서는 701202.
- 화면은 읽은 시트, 가져온 열, 읽지 않은 시트, 채운 업종코드를 불러온 직후 한 줄로 알려 준다.
- 간편장부에 없는 정보(건물·보증금·대출·기초 잔액·부가세 신고서 값 등)는 사용자가 입력하는 것으로 남아 있다.

## 3. 계정과목 어휘와 표준계정 매핑

`계정과목` 열의 실제 값(관찰): `매출액`, `지급이자`, `지급수수료`, `제세공과금`, `기타`. 82호 부표 전체 항목을 어휘로 받는다.

| 계정과목(입력 어휘) | 표준손익계산서 계정 | 비고 |
|---|---|---|
| 매출액 (국세청 서식 표기: `매출`, `기타(수입)`) | 임대수입 (코드 06) | 공급가액만 수입. 부가세는 수입 아님. 구분이 매출이면 계정과목과 무관하게 수입으로 처리하고 어긋나면 경고 |
| 제세공과금 | 세금과공과 (34) | 재산세, 인지세, 교통유발부담금 포함 |
| 임차료 | 임차료 (27) | |
| 지급이자 | 이자비용 (영업외비용) | 코드는 서식 뒷면에서 확인 필요 |
| 접대비 | 기업업무추진비 (39) | |
| 기부금 | 기부금 | 한도 계산 대상, 별도 경고 |
| 감가상각비 | 감가상각비 (35) | **자동 계산**. 거래 시트에 있으면 경고 |
| 차량유지비 | 차량유지비 (45) | |
| 지급수수료 | 지급수수료 (47) | 중개수수료 등 |
| 소모품비 | 소모품비 (51) | |
| 복리후생비 | 복리후생비 (25) | |
| 운반비 | 운반비 (44) | |
| 광고선전비 | 광고선전비 (42) | |
| 여비교통비 | 여비교통비 (26) | |
| 기타 (국세청 서식 표기: `기타(비용)`) | 기타 (사용자 확인) | 아래 거래내역 키워드로 재분류 제안 |

`기타`와 `제세공과금`은 범위가 넓어서 **거래내역 키워드**로 세분 제안을 한다(사용자가 수정 가능).

| 거래내역 키워드 | 제안 |
|---|---|
| 재산세, 인지세, 교통유발부담금, 공과금 | 세금과공과 |
| 관리비 | 건물관리비 (38) |
| 장기수선충당금 | 아래 6장 확인 필요 항목 |
| 보험 | 보험료 (32) |

## 4. 증빙자료 어휘

관찰된 값: `계좌이체`, `신용카드`, `기타(증빙없음)`. 추가로 `세금계산서`, `현금영수증`, `계산서`를 받는다. `기타(증빙없음)`이 비용 행이면 경고한다(영수증수취명세서 대상 확인). 비고의 `세금계산서발행`은 증빙 열이 아니라 비고에 적혀 있으므로, 비고에 `세금계산서`가 있으면 증빙을 세금계산서로 간주하도록 제안한다.

## 5. 도구가 따로 처리해야 하는 행·열

| 항목 | 관찰 | 처리 |
|---|---|---|
| **간주임대료 행** | 거래내역 `간주임대료`, 구분 `매출`, 날짜 `2024-12-31`(과세연도 밖), 계정과목 `매출액`으로 들어 있고 수입금액 합계에 포함됨 | 거래로 가져오지 않는다. 현금 거래가 아니고 날짜도 이전 연도이다. 보증금·건설비 상당액 입력으로 도구가 다시 계산해 **원본 입력값과 대사**한다(V-9). 복식 장부에서는 손익계산서 항목이 아니라 소득금액 조정(수입금액 가산)으로 취급하는지 확인 필요 |
| **부가세** | 매출은 공급가액 + 10%. 비용은 대부분 부가세 없음(이자, 세금). 일부 비용(중개수수료)은 부가세 있음 | 수입·비용은 공급가액 기준. 부가세는 `부가세예수금/대급금` 처리 방식을 정해야 함(7장 질문 1) |
| **지급이자와 차입금** | 대출이자가 비용의 큰 부분. 비고에 대출원금·이율이 적혀 있음 | 이자만으로는 부채가 없다. **차입금 기초·기말 잔액을 대출별로 입력**받아야 재무상태표가 닫힌다. 비고에서 원금·이율을 추출해 입력 초기값으로 제안 |
| **사적 대출이 섞였을 가능성** | 비고에 주택예금담보대출, 연금담보 대출, 가족 간 차용금 이자가 있음 | 필요경비 인정 여부는 세법 판단이므로 도구는 결정하지 않고 "용도 확인" 경고를 띄운다 |
| **장기수선충당금 반환** | 메모에는 임대인 지출(기타비용)로 처리하라고 되어 있음 | 복식에서는 수령 시 부채(예수금)였다면 반환이 비용이 아닐 수 있다. 사용자·세무사 확인 항목으로 표시 |
| **취등록세** | 메모: 취득가액에 포함, 비용 아님 | 거래에 있으면 비용에서 제외하고 건물 취득가 입력으로 유도 |
| **빈 열/행** | 시트 범위가 실제 데이터보다 큼 | 완전히 빈 행은 무시 |

## 6. 검증 규칙

| 번호 | 규칙 | 심각도 |
|---|---|---|
| V-1 | 날짜가 과세기간(1.1~12.31) 안인가 | 오류. 단 간주임대료 행은 5장 처리 |
| V-2 | `구분`이 `매출`/`비용`인가, 공급가액이 있는가 | 오류 |
| V-3 | `공급대가 = 공급가액 + 부가세`인가 | 경고 |
| V-4 | 계정과목이 어휘에 있는가 | 경고 |
| V-5 | 비용 행의 증빙이 `기타(증빙없음)`/비어 있는가 | 경고 |
| V-6 | 거래 시트에 `감가상각비`가 직접 있는가 | 경고 |
| V-7 | 지급이자가 있는데 해당 대출의 차입금 잔액 입력이 없는가 | 경고 |
| V-8 | 사업장별 `매출 합계`, `비용 합계`를 82호 서식 시트의 ⑪, ㊵와 대사(감가상각비 차이 설명) | 정보 |
| V-9 | 도구가 계산한 간주임대료와 원본의 간주임대료 행 금액 대사 | 정보/경고 |
| V-10 | 월별 임대료 누락·중복 | 정보 |

## 7. 이 파일로 확인한 대사 사례 (익명)

| 사업장 | 매출 합계 | 거래 시트 비용 합계 | 82호 부표의 감가상각비 | 82호 필요경비 합계 | 소득금액 |
|---|---|---|---|---|---|
| 1 | 38,536,919 (간주임대료 포함) | 18,222,808 | 6,999,750 | 25,222,558 | 13,314,361 |
| 2 | 29,632,399 (간주임대료 포함) | 14,168,211 | 7,450,155 | 21,618,366 | 8,014,033 |
| 3 | 0 | 3,180,151 | 0 | 3,180,151 | -3,180,151 |

- 거래 시트 비용 합계 + 감가상각비 = 82호 필요경비 합계 (사업장 1: 18,222,808 + 6,999,750 = 25,222,558 ✓ 단, 82호의 기타 686,570은 거래 시트 비용에 포함되어 있음)
- 사업장 3은 비용만 있고 소득금액이 음수(결손)이다. 기장세액공제와 결손금 처리(사업장 합산 소득금액)를 확인해야 한다.
- 위 값은 도구의 회귀 테스트 사례 B로 쓴다(PRD 10장의 사례 A와 별개의 납세자).

## 9. 열린 질문

1. **부가세 처리**: (a) 부가세예수금/대급금을 계정으로 두고 납부 내역을 입력받을지, (b) v1은 공급가액 기준으로만 만들고 부가세는 제외할지. 간편장부에는 부가세 납부 내역이 없다. 제안: (b)로 시작.
2. **간주임대료의 복식 처리**: 손익계산서에 넣지 않고 소득금액 조정으로 둘지(세무사 확인).
3. **사업장별 재무제표**: 기장세액공제 한도는 사업장 합산 기준이다. 재무상태표·손익계산서를 사업장별로 낼지, 합산하여 낼지(82호도 사업장별 구분).
4. **사업장별 건물 정보**: 호실마다 취득가·면적·내용연수가 다르다. 입력 단위는 사업장당 1건물로 가정.
5. 사적 용도 대출 이자의 필요경비 처리 판단 주체(사용자 선택 체크박스로 제외 가능하게 할지).
6. 감가상각비를 필요경비로 계상할 때 조정명세서 첨부가 필요한지: 국세청 FAQ 텍스트는 필요하다고 하고 실제 엑셀 메모는 간편장부대상자는 불필요라고 한다. 상세는 [simple-ledger-guide.md](simple-ledger-guide.md) 10장.
7. 국세청 공식 서식 형식(금액/부가세가 ⑤⑥에 각각 두 칸, 비고에 세계·현영 약어)의 장부도 읽을지. 지금은 사용자의 엑셀 형식만 읽는다. 비고 약어는 증빙으로 해석하는 것을 고려.
