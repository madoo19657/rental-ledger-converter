# v1 범위: 사업장 1곳 (사례 B-1)

실제 간편장부의 3개 사업장 중 **1곳(이하 사업장1)** 만 먼저 구현한다. 다른 두 곳은 같은 엔진에 데이터만 추가하면 되도록 입력 단위를 "사업장 1건"으로 설계하고, 사업장 합산(기장세액공제 한도)은 v1.1로 미룬다.

선택 이유: 수입·비용이 모두 있고(결손 아님), 지급이자·세금·중개수수료·충당금 반환·간주임대료 행·부가세가 모두 들어 있어 변환 규칙을 가장 폭넓게 시험할 수 있다.

## 1. 입력 데이터와 기대값 (사례 B-1)

테스트 입력: [case-b-site1.csv](../samples/case-b-site1.csv) (원본 44행, 상호는 비움, 날짜순 정렬). 아래는 파일에서 직접 합산한 값이다.

| 항목 | 금액(원) | 근거 |
|---|---|---|
| 임대료 (공급가액, 12건) | 37,300,000 | 1월 3,200,000 + 2~12월 각 3,100,000 |
| 간주임대료 행 (원본에 매출로 입력됨) | 1,236,919 | 날짜 2024-12-31 |
| 매출 합계 (82호 ⑪) | 38,536,919 | 위 둘의 합 |
| 지급이자 | 12,712,290 | 대출이자 26건 |
| 제세공과금 | 1,823,948 | 재산세 건축물 1,092,150 + 재산세 토지 616,938 + 교통유발부담금 114,860 |
| 지급수수료 | 3,000,000 | 중개수수료 (부가세 300,000 별도) |
| 기타 | 686,570 | 장기수선충당금 반환 |
| 거래 시트 비용 합계 | 18,222,808 | |
| 감가상각비 (82호 부표에만 있음) | 6,999,750 | 도구가 계산한 값과 대사할 기준 |
| 필요경비 합계 (82호 ㊵) | 25,222,558 | 18,222,808 + 6,999,750 |
| 소득금액 (82호 ⑲) | 13,314,361 | 38,536,919 − 25,222,558 |

간주임대료 행을 거래에서 빼고 도구가 다시 계산하는 경우의 소득금액은 `37,300,000 − 25,222,558 + 재계산 간주임대료`이다. 도구가 계산한 값이 1,236,919와 다르면 그 차이를 대사 화면에 보여 준다.

## 2. 아직 없는 입력 (사용자가 줘야 함)

간편장부에는 없는 정보라서, 이게 있어야 복식 재무상태표가 닫힌다.

| 번호 | 항목 | 쓰임 |
|---|---|---|
| I-1 | 건물분 취득가액, **토지분 취득가액**(입력란 추가됨), 취득일, 연면적, 보증금 받고 임대한 면적, 내용연수/상각방법 | 감가상각비 재계산(기대값 6,999,750과 대사), 건설비 상당액(건물분만), 재무상태표 토지(코드 39) |
| I-2 | 2025-01-01 기초 현금·예금 잔액 | 현금계정 |
| I-3 | 2025-01-01, 2025-12-31 건물 감가상각누계액 | 재무상태표 |
| I-4 | 임대보증금: 일자별 금액(비고에 "25년 2월부터 보증금 4천만원"이 있음), 과거 보증금 | 부채, 간주임대료 적수 |
| I-5 | 대출별 기초 잔액·상환 내역 (은행별 원금) | 차입금 부채, 이자 대응 |
| I-6 | 자본(사업주 자본) 기초, 사업주 인출·투입 | 대차 균형 |
| I-7 | 부가세 처리 방식 선택. "추적"을 고르면 부가세 신고서의 **납부(환급) 내역(일자·금액)과 기초 미납 부가세**도 입력 (G-2 구현됨) | 명세 9장 질문 1 |
| I-8 | 이 사업자의 종합소득 산출세액·종합소득금액(신고서 값) | 기장세액공제 (사업장1의 비율 = 사업장1 소득 ÷ 종합소득) |

I-1, I-4, I-5가 없으면 감가상각비·간주임대료·차입금을 만들 수 없어서 재무상태표를 만들 수 없다. 이 세 가지가 가장 급하다.

## 3. 엔진 구성 (순수 함수, 서버 없음)

```
parseLedger(xlsx|csv)  →  거래[]            입력 파싱, 열 매핑, 정규화
validate(거래[], 설정)  →  경고[]            명세 6장 V-1~V-10
toJournal(거래[], 설정) →  분개[]            6장 분개 규칙, 간주임대료 행 제외
trialBalance(분개[])   →  시산표             차변=대변 검증
statements(시산표)     →  재무상태표, 손익계산서
deemedRent(보증금[], 건물)  →  간주임대료    별지 53호 계산
bookkeepingCredit(소득, 산출세액, 종합소득)  →  기장세액공제
adjustmentStatement(손익, 간주임대료, 조정입력)  →  조정계산서(별지 제46호)
render(...)            →  HTML/PDF         법정 서식 레이아웃
```

- 금액은 모두 정수(원). 날짜는 문자열 `YYYY-MM-DD`로 정규화.
- 세법 값(이자율, 공제율, 한도)은 `tax-params/2025.json`으로 분리.
- 각 단계는 입력과 출력만 가진 함수로 만들어 단위 테스트가 가능하게 한다.

## 3-2. 조정계산서 (별지 제46호) — 추가

복식부기로 신고할 때 첨부하는 서류. 첨부 신고서 8쪽의 양식 기준이다. 자기조정이면 본인이, 외부조정이면 세무사가 작성한다. 도구는 초안 값을 계산하고, 필요경비 불산입 같은 판단은 사용자 입력에 맡긴다.

| 칸 | 항목 | 계산 |
|---|---|---|
| ⑨ | 소득구분 | 30(부동산임대업, 주택임대 제외) 기본. 사용자 선택 |
| ⑩ | 결산서상 당기순이익 | 표준손익계산서의 당기순이익 (엔진 `statements.income.netIncome`) |
| ⑪ | 총수입금액산입 및 필요경비불산입 | 간주임대료(사용 모드 값) + 사용자 입력 조정 합계 |
| ⑫ | 필요경비산입 및 총수입금액불산입 | 사용자 입력 조정 합계 |
| ⑬ | 차가감소득 | ⑩ + ⑪ − ⑫ |
| ⑭ | 기부금 한도초과액 | 사용자 입력 (v1은 0) |
| ⑮ | 기부금이월액 중 필요경비 산입액 | 사용자 입력 (v1은 0) |
| ⑯ | 해당 과세기간 소득 | ⑬ + ⑭ − ⑮ |
| ⑰~㉑ | 세무대리인 성명, 전화, 대리구분, 관리번호, 조정반번호 | 입력 또는 공란 |

기대값
- 사례 A(첨부 신고서): ⑩ 16,915,823 / ⑪ 0 / ⑫ 0 / ⑬ 16,915,823 / ⑭ 0 / ⑮ 0 / ⑯ 16,915,823. 소득구분 30.
- 사례 B-1, 간주임대료 원본값 사용(`asEntered`): ⑩ 12,077,442 / ⑪ 1,236,919 / ⑬ 13,314,361 / ⑯ 13,314,361. 이는 82호 ⑲와 일치한다.
- 사례 B-1, 재계산 모드(현재 가정값): ⑪ 0, ⑯ 12,077,442. 원본과 차이는 대사 경고로 표시한다.

82호 입력칸과의 대응 (홈택스 간편장부소득금액계산서 화면, 출처 S10, 서식 구조는 S2·S4)

| 홈택스 82호 칸 | 의미 | 조정계산서 칸 | 조정 종류 |
|---|---|---|---|
| 12 | 수입금액에서 제외할 금액 | ⑫ | 총수입금액 불산입 (`excludeIncome`) |
| 13 | 수입금액에 가산할 금액 (간주임대료, 보험차익 등) | ⑪ | 총수입금액 산입 (`addIncome`) + 간주임대료 자동 |
| 16 | 필요경비에서 제외할 금액 | ⑪ | 필요경비 불산입 (`disallowExpense`) |
| 17 | 필요경비에 가산할 금액 | ⑫ | 필요경비 산입 (`allowExpense`) |

`adjustment.form82`에 12·13·16·17번 값이 들어 있고 `⑪ = 13 + 16`, `⑫ = 12 + 17`을 테스트로 보장한다. 화면 "조정계산서" 탭에 같은 표를 보여 준다.

구현 상태 (2026-10-31): **엔진과 화면 구현 완료.** `src/engine.js`의 `adjustmentStatement()`, 결과 탭 "조정계산서", 입력란(소득구분, 기부금 ⑭⑮, 조정 항목 표, 세무대리인).
- `run()`의 `taxableIncome`은 이제 ⑯ 값이다. 결과의 `adjustment`에 ⑩~⑯과 ⑪·⑫ 내역이 들어 있다.
- (G-4) 보증금 이자수익이 있으면 ⑫에 "보증금 이자수익 불산입" 항목이 **자동**으로 들어간다. 결산서상 당기순이익(⑩)에 영업외수익으로 들어 있는 예금이자(이자소득)를 사업소득금액에서 빼는 것이다. 그래서 이자수익이 있어도 ⑯은 그대로다.
- 사용자 입력 조정 항목은 `[{kind:'addIncome'|'disallowExpense'|'allowExpense'|'excludeIncome', amount, reason}]` 형태로 받아 ⑪(산입·불산입)과 ⑫(산입·불산입)로 합산한다. 금액 0은 무시, 음수와 알 수 없는 종류는 예외.
- 테스트: 사례 A, 사업장1(원본 간주임대료 모드 ⑯ 13,314,361), 사례 C, 조정 합산, 잘못된 입력.
- 남은 것(F-26 일부): 82호 ⑲와의 자동 대사는 화면에서 손익계산서 순이익과의 일치만 확인한다. 법정 서식 레이아웃 PDF는 아직 없다.
- 사업장이 여러 곳이면 조정계산서도 사업장별이다(v1은 1곳).
- 감가상각비를 필요경비에 넣은 경우 조정명세서 첨부 여부는 안내문과 엑셀 메모가 서로 다르다(9장 질문 참고). 도구는 안내 문구만 표시한다.

## 3-3. 사례 D (블로그 S11·S12, 2020년 귀속) — 회귀 테스트 후보

복식부기 셀프 작성 사례. **G-1~G-4(토지, 부가세 정산, 부가세법 간주임대료, 보증금 이자수익) 구현으로 전체가 테스트(`사례 D: 복식부기 장부 → …`)로 재현된다.** 입력: 월 임대료 4,500,000원 12건(부가세 별도), 비용 8건, 토지 600,000,000원, 건물 100,000,000원(20년 정액법), 기초 현금 500,000,000원(기초 대출 150,000,000원과 보증금 350,000,000원이 현금으로 들어와 있다고 본 값. 블로그의 연중 대출 200,000,000원·상환 50,000,000원은 기초 잔액 150,000,000원으로 단순화), 이자수익 1,500,000원, 부가세 납부 4,100,000원, 부가세법상 간주임대료 6,000,000원. 주의: 소득세 간주임대료는 블로그 값(6,000,000원)을 그대로 쓰는 `asEntered` 모드로 재현한다(PRD 열린 질문 11).

| 항목 | 기대값 |
|---|---|
| 표준재무상태표 자산총계 / 부채총계 / 자본총계 | 1,236,630,000 / 501,550,000 / 735,080,000 |
| 합계잔액시산표(결산 후) 차변합계 = 대변합계 | 1,421,200,000 |
| 당기순이익 | 35,080,000 (매출 54,000,000 − 판관비 16,420,000 + 이자수익 1,500,000 − 이자비용 4,000,000) |
| 조정계산서 ⑪ / ⑫ / ⑯ | 6,020,000 / 1,500,000 / 39,600,000 |
| 조정후 총수입금액 / 필요경비 / 소득금액 | 60,020,000 / 20,420,000 / 39,600,000 |
| 기장세액공제 (산출세액 4,635,000) | 927,000 |
| 세액공제 합계 (표준 70,000 + 기장 927,000 + 전자신고 20,000) | 1,017,000 |

주의: 이 사례의 ⑪ 6,000,000원은 부가세 신고서의 간주임대료로, 53호 방식과 다르다(PRD 열린 질문 11). 도구는 53호 방식을 쓰므로 ⑪을 6,000,000원으로 재현하려면 간주임대료를 직접 입력하는 조정 항목을 써야 한다.

## 5. 수용 기준

1. 사례 B-1 입력에서 매출 38,536,919, 거래 비용 18,222,808이 정확히 재현된다.
2. I-1 입력으로 계산한 감가상각비가 6,999,750과 일치하거나, 차이가 설명된다.
3. 시산표 차변합계 = 대변합계, 자산 = 부채 + 자본이 성립한다.
4. 간주임대료 재계산 값과 원본 1,236,919의 대사 결과가 표시된다.
5. 기장세액공제 값이 신고서 산출세액을 넣으면 `산출세액 × 사업장1 소득 ÷ 종합소득금액 × 20%`와 일치한다.
6. 조정계산서 ⑩~⑯이 3-2장의 기대값과 일치한다. ⑯은 `taxableIncome`과 같고, 원본 간주임대료 모드에서 사업장1의 82호 ⑲(13,314,361)와 일치한다.

## 6. 관찰 하나 (세무사 확인 필요)

원본의 간주임대료 1,236,919원은 거래 시트에 그냥 매출로 들어가 있다. 장부를 기록한 사업자는 보증금에서 건설비 상당액(건물 취득가 중 해당 면적분)을 뺄 수 있는 것으로 알고 있는데, 이 값이 그 차감을 반영했는지는 파일만으로는 알 수 없다. I-1과 I-4를 받으면 도구가 재계산해서 차이를 보여 줄 수 있다. 그 결과가 다르더라도 신고 값을 바꾸는 판단은 세무사와 해야 한다.
