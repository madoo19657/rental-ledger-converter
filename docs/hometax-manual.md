# 홈택스 신고 매뉴얼: 간편장부대상자가 복식부기로 기장세액공제 받기

- 상태: 초안 v0.1 (2026-10-31)
- 출처: 사용자가 제공한 설명 텍스트(원 출처 미상, S6) + 실제 신고서 PDF(S1)와 대조 + 세무사 블로그(S8)·토스인컴(S9). 목록은 [sources.md](sources.md). **홈택스 화면과 국세청 안내, 법령 원문은 직접 확인하지 않았다.** 아래 "확인됨/미확인" 표시를 따른다.
- 이 문서는 도구(rental-ledger-converter)가 만든 서류를 신고에 쓰는 절차를 정리한다. 도구는 서류를 만들 뿐 신고·제출을 대신하지 않는다.

## 1. 한 줄 요약

기장의무는 원래대로 **간편장부대상자**로 두고, 신고유형만 **복식부기(자기조정 또는 외부조정)** 로 고른 뒤, 복식부기 서류를 첨부하고 **기장세액공제 칸에 공제액을 직접 입력**한다. 자동으로 공제되지 않는다.

## 2. 신고 화면에서 고르는 값

| 단계 | 화면 항목 | 선택 | 근거 |
|---|---|---|---|
| 1 | 종합소득세 신고 → 기본정보 입력 | | 제공 자료 |
| 2 | **기장의무** | **간편장부대상자** (원래 유형 유지) | 제공 자료. 신고서 PDF 1쪽 기장의무 코드 02(간편장부대상자)로 확인됨 |
| 3 | **신고유형** | **복식부기-자기조정** 또는 **복식부기-외부조정** | 제공 자료. PDF에서 신고유형 코드 12(외부조정) 확인됨 |
| 4 | 세액공제 입력 | **기장세액공제**에 공제액 입력 | 제공 자료. PDF 5쪽 세액공제명세서 기장세액공제(코드 236)에 값이 입력되어 있음 |

주의
- 기장의무를 "복식부기의무자"로 잘못 고르면 실제 의무와 달라져 오류가 난다. 간편장부대상자는 그대로 둔다.
- 코드표(신고서 서식): 기장의무 1 복식부기의무자, 2 간편장부대상자, 3 비사업자. 신고유형 11 자기조정, 12 외부조정, 13 성실납세, 14 성실신고확인, 20 간편장부, 31 추계-기준율, 32 추계-단순율. 복식부기로 기장한 간편장부대상자는 20(간편장부)을 고르면 안 된다.
- 자기조정과 외부조정의 차이: 자기조정은 본인이 조정계산서를 작성, 외부조정은 세무사 등이 작성. 어느 쪽이 가능한지와 조정계산서 작성 방법은 **미확인**이다.

## 3. 제출할 서류

제공 자료가 든 필수 서류 4종과, 실제 신고서 PDF에 더 첨부되어 있던 서류를 구분한다.

| 서류 | 제공 자료 | 실제 신고서 PDF | 이 도구가 만드는가 |
|---|---|---|---|
| 표준재무상태표 (별지 제40호의6) | O | 16~17쪽 | **O** |
| 표준손익계산서 (별지 제40호의7) | O | 18~19쪽 | **O** |
| 합계잔액시산표 (별지 제40호의9) | O | 20~23쪽 | **O** |
| 조정계산서 (별지 제46호) | O | 8쪽 | **있음** (화면 "조정계산서" 탭). 홈택스에는 화면 입력 |
| 소득금액조정합계표 (별지 제47호) | 언급 없음 | 없음(조정이 없어서) | **아직 없음**. S12: 자기조정 + 세무조정이 있으면 PDF 부속서류로 직접 첨부 |
| 기장세액공제신청서 (별지 제10호의3) | 언급 없음 | 14쪽 | 값 계산만 (화면 "대사·계산근거" 탭) |
| 임대보증금등 총수입금액조정명세서 (별지 제53호) | 언급 없음 | 11~12쪽 | 계산만 (같은 탭) |
| 조정후총수입금액명세서, 총수입금액조정명세서 | 언급 없음 | 9~10쪽 | 아직 없음 |
| 영수증수취명세서 | 언급 없음 | 13쪽 | 아직 없음 |
| 전산조직운용명세서 | 언급 없음 | 15쪽 | 아직 없음 |

- 제공 자료는 "재무상태표, 손익계산서, 합계잔액시산표, 조정계산서"를 필수로 든다.
- 신청서, 간주임대료 명세서, 영수증수취명세서, 전산조직운용명세서는 세무사가 낸 실제 신고서에는 들어 있었지만 제공 자료에는 없다. 간편장부대상자에게 반드시 필요한지는 **미확인**이다.

## 4. 기장세액공제 금액

- 공제액 = 종합소득 산출세액 × (기장소득금액 ÷ 종합소득금액) × 20%, 한도 연 100만 원. 신고서 서식에 적힌 계산식이다. (확인됨)
- 사례: 산출세액 684,949원, 기장소득금액 = 종합소득금액 → 136,989원 (원 미만 절사). (확인됨)
- 사업장이 여러 곳이면 한도 100만 원은 사업장별 공제의 합계 기준이다. (서식 설명, 확인됨)
- 간편장부로만 기록하면 2025년 귀속에는 이 공제가 없다. 복식부기로 기록해야 한다. (서식 설명, 확인됨)

### 4-1. 요건과 배제 사유 (세무사 블로그, 2024-12-08 [C], 법 조문 미확인)

- 요건: 간편장부대상자, 복식부기로 기장해 소득금액 계산, 확정신고 때 서류 제출. [C]는 "세무대리인의 도움을 받아"라고 적었으나 토스인컴 글([D], 2026-10-16)은 이를 요건에 넣지 않았다. 법정 요건으로 보지 않는다.
- 제출 서류 [D]: 재무상태표·손익계산서와 부속서류, 합계잔액시산표, 조정계산서(소득세법 제70조), **기장세액공제신청서**(시행령 제116조의3, 확정신고서에 첨부해 관할 세무서장에게 신청). 이로써 아래 H-4(신청서가 별도 제출 서류인가)는 "별도 제출 서류"로 보는 쪽이 맞다.
- 배제: 신고할 소득금액의 20% 이상을 누락한 경우, 장부와 증빙을 확정신고기간이 끝난 날부터 5년간 보관하지 않은 경우(부득이한 재해·도난은 예외).
- 출처: [sources.md](sources.md) S8, S9. 조문 원문은 미열람.
- 관련 자료와 간편장부 작성법: [simple-ledger-guide.md](simple-ledger-guide.md)

### 4-3. 복식부기(자기조정) 화면은 S12가 확인해 준다
- S12(송채훈 회계사 2부)가 **복식부기 자기조정** 신고 화면을 35장의 캡처로 보여 준다. 화면별 입력값은 [hometax-double-entry-flow.md](hometax-double-entry-flow.md).
- 위 17단계 표의 4~5번(총수입금액 및 필요경비계산 명세서, 간편장부 소득금액 계산서)은 **간편장부 신고용**이고, 복식부기 신고에서는 **02 소득금액명세서의 조정계산서, 조정후 총수입금액명세서, 표준재무상태표·손익계산서·원가명세서·합계잔액시산표, 사업소득명세서** 화면으로 대체된다.
- 12번 기장세액공제 입력 위치는 추정이 아니라 **08 세액공제·감면·준비금 → 기장세액공제신청서**로 확인되었다(S12).

### 이 화면 흐름이 알려 주는 것
- **신고유형은 사업장 단위**다. 이 도구도 사업장(시트)별로 계산하므로 구조가 맞다. 사업장1만 복식, 나머지는 간편장부처럼 섞을 수 있는지는 미확인(H-6).
- 기장세액공제는 사업장 합산 한도(100만 원)와 비율 계산이 필요하므로, 사업장별 소득금액을 모아서 쓰는 합산 기능이 이후 필요하다.
- 임대 전 사업장처럼 결손이 있는 사업장이 있으면, 이 파일의 임대사업소득계(82호)는 사업장 소득금액을 단순 합산한다(수입 사업장 소득 − 결손 사업장 결손). 결손과 이월결손금 처리는 8번 화면과 세무사 확인 대상이다. 실제 사례 숫자는 `docs-private/`(볼트 정션)에 있다.
- 글은 **간편장부 신고**용이다. 복식부기로 신고할 때 4~5번 화면이 어떻게 달라지는지, 재무제표를 어디에 올리는지는 이 글로 알 수 없다.

## 5. 신고 전 체크리스트

1. 기장의무가 간편장부대상자로 되어 있는가
2. 신고유형이 복식부기-자기조정 또는 복식부기-외부조정인가 (간편장부 20이 아닌가)
3. 재무상태표 자산 = 부채 + 자본인가 (도구의 "표준재무상태표" 탭 차이 0원)
4. 합계잔액시산표 차변합계 = 대변합계인가
5. 간주임대료 원본 값과 재계산 값의 차이를 확인했는가 (도구의 대사 탭)
6. 가정값(노란 칸)이 남아 있지 않은가. 건물 취득가, 면적, 보증금, 대출 잔액
7. 기장세액공제 칸에 공제액을 입력했고 100만 원 한도를 넘지 않는가
8. 장부와 증빙(통장 내역, 세금계산서, 카드 영수증, 취득 서류)을 보관하는가
9. 신고기한 안에 신고하는가
10. 세무사 검수를 받았는가
11. 신고유형을 **사업장마다** 선택했는가 (사업소득 사업장 명세)
12. 지방소득세(위택스)를 따로 신고·납부할 준비가 되어 있는가 (신고서 제출 단계에서 정보 제공 동의)
13. 환급이 있으면 본인 명의 계좌인가
14. 기납부세액(중간예납, 원천징수)이 자동으로 반영되었는지 확인했는가
15. 결손이 난 사업장이 있으면 이월결손금 처리를 확인했는가

## 6. 이 도구와의 차이 (할 일)

- **조정계산서(별지 제46호)**: 구현 완료(화면 "조정계산서" 탭, [scope-v1.md](scope-v1.md) 3-2장). 홈택스에는 화면에 직접 입력한다(S12).
- **소득금액조정합계표(별지 제47호)와 53호 PDF 출력**, **조정후 총수입금액명세서**, **사업소득명세서 값**, **결산 후 합계잔액시산표 4열 레이아웃**은 아직 없다. PRD F-29~F-33.
- 소득금액조정(세무조정)이 필요한 항목, 예: 간주임대료 가산, 필요경비 불산입(사적 대출 이자 등)은 도구가 경고만 하고 조정은 하지 않는다.
- 제출 서식을 법정 레이아웃 PDF로 내는 기능은 없다. 화면 표와 브라우저 인쇄로 대신한다.

## 8. 원본 자료 (사용자 제공, 가공 전 요약)

- 기장세액공제를 받으려면 기장의무는 간편장부대상자를 유지하고 신고유형만 복식부기 관련 항목을 선택한다.
- 복식부기로 작성한 장부와 재무상태표 등 필수 서류를 함께 제출해야 공제가 정상 적용된다.
- 첨부 서류: 재무상태표, 손익계산서, 합계잔액시산표, 조정계산서
- 단계: 기본정보 입력 → 기장의무 간편장부대상자 → 신고유형 복식부기-자기조정/외부조정 → 신고서 작성 중 기장세액공제 항목에 공제액 입력
- 점검: 기장의무를 복식부기의무자로 잘못 고르지 말 것, 공제 한도 연 100만 원
